Pilot checklist

Things AgentQA cannot check by itself. Agree them with the portal owner before the first run.

{{ ui.icon('lock') }} Permission and environment

  • Written approval from the portal owner to run automated and security tests
  • A test or UAT environment, never production; its address is in Settings
  • Test data that may be created and changed, and a way to reset it (Settings: data.setup)
  • A contact who can restart the environment if a test brings it down

{{ ui.icon('users') }} Accounts and messages

  • One test account per role, plus a second account for one role to test record isolation
  • CAPTCHA switched off or fixed in the test environment
  • OTP SMS and emails routed to the AgentQA inbox, or a fixed test OTP
  • The latest SRS, and who can answer questions about it within a day
